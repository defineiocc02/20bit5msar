## 1. 从系统指标到输入参考噪声上限

全部按 −1 dBFS 正弦、25 °C、Fin = 100 kHz、矩形相干窗口径：

| 量 | 公式 | 值 |
|---|---|---|
| 输入 rms | `(FSR/2)·10^(−1/20)/√2` | **2.581338448 V** |
| 噪声上限（SNR ≥100 dB） | `Vrms / 10^(100/20)` | **25.813384 µV rms** |
| 总误差上限（SINAD ≥98 dB） | `Vrms / 10^(98/20)` | **32.497126 µV rms** |
| 由 SINAD 反推的剩余失真 | `√(total² − noise²)` | 19.741640 µV rms（−102.329 dBc） |
| 谐波上限（THD ≤−105 dBc） | `Vrms · 10^(−105/20)` | **14.515933 µV rms** |
| 若 THD 恰达上限的 SINAD | `20log10(Vrms/√(noise²+thd²))` | 98.8067 dB → **余量 0.807 dB** |

> **THD 是控制项，不是 SINAD**：14.52 µV < 19.74 µV。所以后面所有「建立误差」都要对着 14.52 µV 算，不能拿 SINAD 的 19.74 µV 放宽。
> 这条链与 `docs/MODEL_PLAN.md:75` 的 25.81 / 32.50 µV 与 0.81 dB 余量逐位吻合，是本文与既有设计输入的交叉校验点。

**静态与码域换算**

| 量 | 值 |
|---|---|
| 20-bit LSB = FSR/2²⁰ | **7.8125 µV** |
| 理想量化噪声 = LSB/√12 | 2.255274 µV rms（仅占噪声功率 **0.76%**） |
| INL ≤±4 ppm FSR | **±32.768 µV**（≈4.19 LSB20） |
| DNL <0.99 LSB20 | **<7.734 µV**，无失码 |
| 一级 Δ1 = FSR/2¹⁰ | 8 mV；RA 放大后量化区间 256 mV |
| 二级步长折回输入（FSR2_RA=1.024 V / 2¹¹ / G=32） | **15.625 µV**（19-bit 确定性步长） |
| 1 MHz 扩展指标 | SNR ≥96 dB / SINAD ≥94 dB（单列报告） |

> `SPEC.md:43`：「20-bit 输出字不等于 20-bit ENOB」；98 dB SINAD ≈ 15.99 ENOB。上述 LSB 是码宽，不是精度证明。

## 3. 模块设计约束（可直接取用的数值）

### 3.1 采样网络：电容下限与 28 pF 口径风险

差分 kT/C 采用模型自己的 `σ = √(2k_BT/C_signal)` 口径（`normal_parameters.m:193`）：

```
C_signal ≥ 2·k_B·T / σ_sampling²
         = 2·1.380649e−23·298.15 / (18.2528e−6)²
         = 24.7109 pF        ← Rev0.3 口径的下限
```

当前模型 `C_signal = 28.0521 pF`（`parameters.json` 的 `front.C_f` 前 8 行求和），对应 `σ_ktc = 17.1314 µV rms`，占噪声功率 **44.04%**，在 50% 分配内，余量约 6 个百分点。

> 🚨 **第一个必须先冻结的设计决策**：`spec.yml:57` 明确 `capacitance_definition: "TBD single/differential per-side/total"`，`SPEC.md:59` 也要求确认「单端/差分、每半边/总和」。
> 若 **28 pF 是每半边** → 上述闭合成立；
> 若 **28 pF 是差分总和** → 每半边约 14 pF，`σ_ktc ≈ 24.2 µV rms`，占噪声功率 **约 88%**，采样预算直接崩，且还要重算驱动能力、参考动态负载与芯片面积。
> 这不是文档措辞问题，是决定前端面积与驱动规格的岔路口。`SPEC.md:59` 已警告「不得在增加 bank/pool 后继续宣称总电容、面积和功耗仍等于原型」。

### 3.2 采样开关与建立

以 THD 的 14.5159 µV 为建立误差目标、最坏阶跃 `Vstep = FSR/2 = 4.096 V`：

```
Vstep·e^(−t_acq/τ) ≤ 14.5159 µV  →  t_acq/τ ≥ ln(2.822e5) = 12.550
τ ≤ 12.5 ns / 12.550 = 0.9960 ns
Ron ≤ τ / C_top = 0.9960 ns / 28.1521 pF = 35.38 Ω
```

当前 `Ron_eq = 20 Ω`、`τ_sample = 0.5630 ns` → **一阶通过，余量 44%**。

> 窗口取行为日历 `behavior_calendar.m` 的 `cnv 0 ns → coarse_latch 12.5 ns`，是保守值。Rev0.3 的 A/B ping-pong 用 `200 ns − 非重叠/复位/路由开销`（`SPEC.md:49`、`spec.yml:53`），窗口口径不同；**发布 Ron 规格前必须重算有效 t_acq**，不能用名义 200 ns 直接放宽。

### 3.3 RA 与比较器：预算只在 tracking 成立时才闭合

二者都在级间，折回输入一律除以 `G_RA = 32`：

| 项 | 模型当前值 | 折回输入 | 预算上限 | 一阶判定 |
|---|---:|---:|---:|---|
| RA OU 噪声 `sigma_vx_rms` | 0.512785 mV | **16.0245 µV** | 9.9975 µV | 超 |
| SAR2/TA 比较器噪声 | 0.286929 mV | **8.9665 µV** | 6.8296 µV | 超 |

只有 tracking averaging 把它们压下去才可能闭合：按论文约 7 dB（幅度 ×2.24）得 7.15 / 4.00 µV，按理论 9.03 dB（×2.83）得 5.66 / 3.17 µV，都落进预算。**但这两个倍数是示意，不是实测收益**：`MODEL_PLAN.md:77` 禁止用「滤波前/8」代替闭环协方差，`SPEC.md:71` 也写明 9.03 dB 是理想白误差上限、约 7 dB 需由闭环状态与相关噪声重现。

**可执行规格**：RA 输出噪声 ≤ **319.92 µV rms**、二级比较器输入噪声 ≤ **218.55 µV rms**，条件是 tracking 后的实测输入参考值分别 ≤10.00 / ≤6.83 µV rms。这两条必须由 [M1 单源消融](../../docs/PROJECT_PLAN.md) 给出实测，不能靠假设签收。

另外：SAR1-fine 与 Flash 比较器噪声**明确未实现**（`behavior_ra_noise_guard.m:119`、`behavior_applied_note.m:46`），而 Rev0.3 的 6b 预转换与 SAR1 静态线性度链需要它们。

### 3.4 RA 有限增益 / 带宽

```
NG = 1 + C_top/Cf = 1 + 28.1521 pF / 0.864 pF = 33.5834
τ_RA = NG/(2π·UGB) = 33.5834/(2π·1.2 GHz) = 4.4541 ns
闭环增益误差 ≈ NG/A0 = 33.5834/1e4 = 0.336%
```

0.336% 远超 20-bit 的 ppm 级要求，只能靠 **2-bit 级间冗余 + 前景位权/增益校准** 吸收（`SPEC.md:11,67-71`）。而当前生产工作点 `calibration_mode='off'`，`SAR20('calibration')` 直接抛错 → **这条吸收链完全没有验证证据**。

⚠️ 不要用「12-bit 指数建立需 τ ≤1.39 ns」去判 RA 不合格：二级是 **CINC 连续时间积分器**，不是采样保持节点，指数建立判据不适用。同理 `τ_dac = 0.5 ns` 在朴素指数模型下不满足 2.5 ns 窗口的 0.2774 ns 限值，但 CT 积分模型下不能直接判失败。**这两项的正确做法是推导闭环残差误差传递函数，再定 τ 规格**，属于 M1/M2 的闭环验证，不是查表能给的结论。

### 3.5 时钟 / 孔径 jitter

`SNR_jitter = −20·log10(2π·f_in·σ_t)`，若 jitter 独占全部噪声预算：

| 条件 | σ_t 上限 | 若只给 1% 功率子预算 |
|---|---:|---:|
| Fin 100 kHz，SNR 100 dB | **15.9155 ps** | 1.5915 ps |
| Fin 1 MHz，SNR 96 dB（扩展） | **2.5224 ps** | 0.2522 ps |

当前 `common_sigma_s = local_sigma_s = 0`，jitter 在 normal 工作点 OFF。`MODEL_PLAN.md:71` 的诊断扫点 0 / 0.5 / 1 / 2 / 5 / 10 ps 是探索输入，不是 PDK 统计；ADI 约 0.6 ps 只是该论文的参考值，**不是本项目既定 σ_jitter**。1 MHz 扩展指标实质上把孔径噪声要求收紧约 6.3 倍，是时钟设计最紧的一条。

### 3.6 参考 / 驱动、AZ、数字、静态、接口

| 模块 | 可执行上限 | 现状 |
|---|---|---|
| 参考 / 驱动 | 输入参考 **≤8.1629 µV rms**；外部 4.096 V 低噪声参考 + VREF/REFCAP 动态负载网络（`SPEC.md:35`） | `reference_noise` / `reference_recovery` **not implemented**（`behavior_backend_step.m:434-437`、`behavior_ra_noise_guard.m:90`）；10% 预算完全无模型 |
| AZ | 输入参考 **≤7.3011 µV rms**；写窗 0–31.25 ns、POL `[+1,−1,−1,+1]` | 只有 ordinary AZ；`az_noise` **not implemented**；8% 预算完全无模型。CAAZ 另见 `CHOP_AZ_SPEC.md`，其「同带宽滤波」口径不得写成 5 MS/s 全带宽降噪 |
| 数字重构 | 预算 **5.7720 µV rms**；20-bit 量化仅占 0.76%，余量 4.24% | 系数定点化、舍入、饱和、冻结校准误差未验证（`MODEL_PLAN.md:67`）；`nominal.mat` 权重来自名义几何，不是实际电容 |
| 静态线性度 | INL **±32.768 µV**、DNL **<7.734 µV** | 无码密度 / DNL / INL 测量；`MODEL_PLAN.md:114` 要求含噪置信度与记录量 |
| LVDS 接口 | 32-bit 帧 `W[31:0]={D1,D2,DT,VALID}`、250 MHz burst、N−2 固定读槽、原码提交 ≤370 ns | transport OFF 且未接生产图（`SPEC.md:109` 明确无 SLX 编译/运行证据） |

## 4. 三个会直接改变设计的发现

1. **量程口径把噪声预算放大 1.49 倍**。同一颗 28 pF 电容，在 10 V normal 口径下只占 29.56% 噪声功率，在 Rev0.3 8.192 V 下占 44.04%。「当前模型跑出 99 dB」不能外推成「产品能到 100 dB」——换量程、开校准、开接口之后预算会更紧。
2. **28 pF 的定义没冻结，是面积/驱动/参考负载的分水岭**。`spec.yml:57` 的 `TBD` 使 C_signal 可能是 28 pF 也可能是 14 pF；后者让采样预算从 44% 跳到约 88%，整个分配表要重做。这应该是下一个设计评审的第一个议题。
3. **18% 的噪声功率没有任何模型**（AZ 8% + 参考/驱动 10%），另有 RA/比较器 22% 依赖未实测的 tracking 收益。也就是说**当前行为模型最多只能对 60% 左右的预算给出一部分解析约束**，其余 40% 是空的或待闭环验证。这解释了为什么「感觉没办法拿来指导设计」——不是模型跑不通，是它与设计目标之间缺这条预算链。

## 5. 闭合状态与验证门

**`closure.verdict = NOT_CLOSED`**（`verify_budget.py` 每次运行都会打印）。阻塞项：

| # | 阻塞项 | 解除方式 | 归属里程碑 |
|---|---|---|---|
| 1 | 28 pF 口径 TBD | 冻结「每半边 / 差分总和」，重算 C、驱动、参考负载、面积 | 设计评审（不需仿真） |

| 4 | 静态 DNL/INL、数字系数、LVDS 无证据 | 码密度测试、定点链对照、接口集成 | M2 / M3 |
| 5 | 当前工作点非 Rev0.3 配置 | 不得用 10 V / N256 / 校准 OFF 的结果判达标 | 全程口径纪律 |

**模型覆盖率盘点**：有模型可解析的分配 = 50% + 15% + 7% + 5% = **77%**；完全未实现 = **18%**；余量 = **5%**。但「有模型」≠「已通过」：77% 里只有采样 kT/C、采样 RC、量化三项有一阶解析通过，RA/比较器/系数/校准仍需实测。

### 能声称 / 不能声称

✅ **能声称**：Rev0.3 → 模块数值上限的解析链可复现、自洽（79 项校验全绿）；采样 kT/C、输入 RC、量化三项当前假设参数满足一阶上限；「还缺什么」已被逐项列成可验收的门。

## 6. 与项目计划的接口

本闭环是 [M1 单源消融](../../docs/PROJECT_PLAN.md) 的**验收依据**，不是替代它：

- M1 的每个 leave-one-out case 都应报出该模块的输入参考 ΔµV，与本表 `rms_limit_uv` 对照；
- M1 的 F 组（M1/M8 tracking 对照）给出真实 tracking 增益，才能把 §3.3 的 2.24 / 2.83 近似倍数换成实测值；
- M2 的 20k 点谱与静态测试对应 §3.5 / §3.6 的扩展与静态门；
- 只有这些门过完，才能讨论 M3 晋升或任何「设计达标」措辞。

> 本文件与计划文档都不授权改 `current/`、SLX 或仿真结果。N 系列实现（AZ/参考噪声）属架构级改动，须单独立里程碑并显式授权。
