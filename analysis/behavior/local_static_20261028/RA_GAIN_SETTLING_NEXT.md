# RA 有限增益与建立：下一步设计者检查

**实际节点。** 最近负端 −1.9073486328125 nV，120823 的 A0=100000 和 Inf 均得到 RAW `[1039,3417,213]`、码524288，配对0 V均码524289；但75 ns实际 VX为255.897276/255.984281 mV、VY为+309.365/+377.117 µV。八次TA最小 `|VY|` 分别约70.114/2.358 µV，零端部分VY约 `+9.214e−18 V`。同码不等于同模拟裕量；这些是无比较器噪声模型的单点阈值距离，不是器件可靠性。三点为scratch实跑，与旧主图1e4锚点尚无同P跨环境逐位门。独立复算八次TA：RA残差≤5.56e−17 V、CT矩阵残差≤9.22e−18 V；CT符号由RAW/事件重建，不是逐电容探针。[原始数值](nodes_120823.json)、[只读脚本](audit_120823_nodes.py)。

**一阶预算示例。** 本点 `Qres/Cf≈255.999939 mV`、`NG≈34`、名义信号增益32。固定目标、AZ/Vos off、匹配replica且τDAC=0时，`F=A0/(A0+NG)`、`E_gain=|Qres/Cf|(1−F)/32`：若单独分配0.5 LSB，需 A0≥69598 V/V（96.85 dB）；A0=1e5时约2.719 µV=0.348 LSB。首TA距RAstart 43.75 ns，τ=NG/(2πUGB)：UGB=1.2 GHz时建立尾量约0.489 µV=0.0626 LSB；若示例分配0.1 LSB，UGB约需≥1.142 GHz，1.2 GHz只高5.1%。在A0=1e5时本点两项合计约0.411 LSB，尚不包括量化、噪声、失调、有限DAC或参考。首D2更早，同式尾量约48.5 LSB输入参考，须考虑冗余和后续判决，不能称最终ADC误差。这些均非批准规格；真实A0/UGB、相位裕度、摆幅、负载与PVT需共同验证。

**优先实跑，均固定M8、校准关闭并保留P/SLX/源码、实际RAW/valid及节点：**

1. **多幅度/频点，8条N256。** 同一scratch、A0=1e4和1e5、UGB1.2 GHz；Fs=5 MHz、ID4–259/epoch1、phase=0.731、pool seed=20269121，峰值 `2.048/3.650563842595822 V`，相干bin `5/127`（97.65625 kHz/2.48046875 MHz）；失配/AZ/噪声off，τDAC/采样/预充0。plan_rows取264、清空旧plan后prepare，并核同seed计划前缀。N256仅筛查；近Nyquist测试不证明真实输入网络带宽。
2. **UGB与RA失调。** A0=1e5，最近负端和0 V各测UGB=0.9/1.5 GHz，共4个N1，复用已测1.2 GHz；固定目标式首TA建立尾量约0.708/0.00554 LSB，仅作解释。另在AZ off下用 `P.backend.ra.vos_input_v=±0.1 µV` 对两端各跑一次（4个N1），必要时扩至±3 µV。此为RA输入失调；反馈不变时一阶CT敏感度约26.47 VY/Vos，真实新判决可改变预测。
3. **随机源/seed，12条N256。** A0=1e5、UGB1.2 GHz、峰值3.6505638426 V、bin5/127：①仅采样kTC，T=298.15 K、`ktc_seed=[20261027,20261028,20261029]`；②仅孔径端点jitter，示例common25 ps/local10 ps、固定skew0、`jitter.seed=[20261029,20261030,20261031]`。两项各6条，并与第1项noise-off配对；`P.seed`标签不替代两者。3 seed/N256不支持尾概率或最终SNR签核，jitter也不是全时钟抖动。

当前核不实现 RA/AZ/参考随机噪声及Compare2失调/噪声，不能只翻NI标志冒称覆盖；`sar1.coarse_offset`不是TA比较器失调。若要比较器扫描，先隔离实现同一Compare2在D2/TA的失调、噪声与seed，并完成零值原路径位门。以上均是待运行条件；两端中间码仍未测，不能称缺码、全DNL/INL或PDK结果。
