# 零点两实际端点：D1、RA、CT 和数字拼接

本次只读 110315 的 0 V 原生 preflight `simout`，以及 112407 的 −30.517578125 nV 实际点、保存 P 和九路日志；两点均为 ID4/epoch1，前面均有 ID0–3 四次实际转换。保存的负端 P 与 **事后按已固定工厂参数和原 preflight 设置重构** 的 Pzero 仅在 input offset、front/input offset 和 xFE0 有差异；0 V preflight 当时没有独立保存完整 P，不能称 Pzero 是原生另存的当时 P。模型 `63190994...`、两点 source manifest、日志/模型哈希和 110315 的同 P 全/短九路日志位门见 [数值回读](zero_physics.json)；脚本 [audit_zero_endpoints.py](audit_zero_endpoints.py) 不运行模型。工厂条件：固定片池/seed、τDAC=τsample=τprecharge=0、失配/DEM/dither/jitter/kTC/AZ/校准 off，RA A0=1e4、UGB=1.2GHz、CINC 模型 on、匹配反相信号副本 on。

## 真实前端分叉

| 端点输入 | 15 ns 首细判的真实 Vres / Qres | 决策后 D1 | 31.25 ns RAstart 的 Qres、Vres、Qres/Cf |
|---|---|---|---|
| −30.517578125 nV | −30.5175781284 nV / −0.000828598485 fC | 1024 | +217.211292614 fC、+7.999969482 mV、+255.999023437 mV |
| 0 V | 0 / 0 | 1040 | 0、0、0 |

两点 coarse 都是 32；负端首 fine bit=0，后面四位均1，最终 D1=1039（fine=15）；零点首 fine bit=1，后四位均0，最终 D1=1040（fine=16）。即 15→16 的细码进位，不是 coarse 改变。当前模型比较器在此观测到零值取1；真实电路偏置/噪声和亚稳并未包含。真实 FE 方程为 `Qres=Σ(q_initial_j−Σ_g B_jg)`，`Vres=Qres/Cs`。本例 `Cs≈27.151515 pF`，且其理想DAC步长为 `2·4.096/1024=8 mV`；负输入与约8 mV物理残量相加即上表。原日志不是逐电容开关轨迹，不能把这次差值当参考引脚电流。

## 真实 RA 和 CT 的对应关系

两点 `Ctop≈28 pF`、`Cf≈0.84848485 pF`、`NG=1+Ctop/Cf≈34`、`F=A0/(A0+NG)≈0.9966115208`、`τR=NG/(2π·UGB)≈4.509390 ns`。负端 RAstart 实测旧 VX 为约 `1.1552e−62 V`，是模型有限复位后的历史余量，不能无条件说状态被数学清零；零端是0。31.25→43.75 ns 是保持同一 RA 命令、无D1变化的12.5 ns区间。由实际 31.25 ns 的 VX 和 Qres 独立复算 `VX(t)=F(Qres/Cf)+(VX0−F(Qres/Cf))exp(−Δt/τR)`，负端实测 239.176358785 mV，原始差 `5.55e−17 V`；零端均0。这仅验证该实际区间，非所有动态/真实器件。

73.75 ns D2反馈完成后，负端 VX=255.110987084 mV、VY=−0.302930240 mV；零端 VX=0、VY=−0.389357560 mV。依据**保存的** 10+2 CT 电容矩阵、`Vref_CT=1.8 V`、各实际 RAW 推定的 D2 已反馈符号和零 TA 符号，独立求解两半节点矩阵，VY差分别 0 和 `9.22e−18 V`。85 ns 再按 RAW DT 的前7位重建物理TA符号，预测 VY 与日志原始差分别 0 和 `9.22e−18 V`。输入增益 α≈0.77871512。这里轨符号是根据记录 RAW 与已保存控制/事件代码恢复，不是新增的逐片开关探针。匹配反相 replica 使此配置的模型 `switchCharge(main)+switchCharge(replica)=0`；CINC功能虽开启，不等于观察到了非零RA kick，也不代表所有失配/副本条件下均抵消。

## 同一两个RAW的数字贡献

| 名义数字分量（输入参考） | 负端 | 零端 | 零端−负端 |
|---|---:|---:|---:|
| D1（含 −17Cu bias） | −8000 µV | 0 | +8000 µV |
| D2，RAW=3417 / 2374 | +7984.375 µV | +15.625 µV | −7968.750 µV |
| DT，RAW两端均42 | −11.71875 µV | −11.71875 µV | 0 |
| 三项和，取整前 | −27.34375 µV | +3.90625 µV | +31.25 µV = 4名义LSB |
| 实际 code20 | 524285 | 524289 | +4 |

D2计算为 `[−0.5095 V + Σ w_i bit_i]/32`，十二个 `w_i` 取保存 P；两端 RA 域值为 255.5 mV 和 0.5 mV。DT为 `0.25 mV × Σ(8..1)(2b−1)/8/32`，RAW42 的加权统计量为−12；第8个决定仍参与数字重构，但只有前7个物理更新。以上是实际RAW及名义数字代码的精确拆分，不是把最终位模式当每个时刻都已提交的模拟状态。

若**仅**保持负端的实际 RAstart 目标 Qres/Cf、NG 和名义数字gain32不变，稳态相对无限A0的输入参考有限增益差在 A0=1e4 / 2e4 / 4e4 / Inf 分别约 27.108 / 13.577 / 6.794 / 0 µV（3.470 / 1.738 / 0.870 / 0名义LSB）。这是固定目标反事实，并非这些A0的新仿真或最终码差；D2/TA决策和反馈会随A0改变。它说明有限增益是值得实测的量级，不足以宣称唯一根因。

两个实际端点间隔为1/256 LSB且最终码差4；**524286–524288在区间内部是否有平台没有测量**，不能称缺码、填DNL=−1或外推全范围INL/DNL。所示为当前行为模型且固定ID4、四次预热，不是多输入/PVT/硅片结论。
