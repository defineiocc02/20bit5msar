# 110315 三阈值局部 DC：独立回读

31 个已保存实际点均已从各自 `P.mat`、9 路原始 timeseries 和 `observed.mat` 回读，并与 receipt/SHA 对照。每点有 ID0–3 四次实际预热及 ID4 目标转换，五次的 RAW/ready/epoch/valid 均正确，每 ID 有实际 48 个事件；ID4 的公开 RAW 独立重算整数码与实际 Code 一致。实际 held 与请求 DC 的最大差为 `6.78e−21 V`，小于原预声明输入轴门。31 个实测点按输入排序后没有观察到反向码。

固定名义 LSB 为 `8.192 V / 2^20 = 7.8125 µV`。从四个端点和逐次实际二分结果重新构造得到：

| 进入码 | 低端点（µV） | 高端点（µV） | 区间宽度（nV） |
|---|---:|---:|---:|
| 524290 | 7.827758789 | 7.843017578 | 15.258789 |
| 524291 | 15.670776367 | 15.686035156 | 15.258789 |
| 524292 | 23.513793945 | 23.529052734 | 15.258789 |

每个阈值都经 9 次实际二分；端点分别实际得到相邻低、高码。**若未测输入范围内单调且各包络内只有一次相邻码跃迁**，以 `下一阈值低端−前一阈值高端` 和 `下一阈值高端−前一阈值低端` 为码宽上下界，两码的条件局部 DNL 均为：

| 码 | 条件码宽区间（µV） | 条件 DNL 区间（LSB） |
|---|---:|---:|
| 524290 | [7.827758789, 7.858276367] | [+0.001953125, +0.005859375] |
| 524291 | [7.827758789, 7.858276367] | [+0.001953125, +0.005859375] |

`+0.00390625 LSB` 是区间中点估计，不是单独测得的精确 DNL。闭区间是保守包络，不能确定真实跃迁是否等于某端点，也不能把只对 31 个点的单调观察扩展到未观测位置或全量程。每点五个已观察整数码相同，但这不证明内部状态对所有输入已达到一般稳态。INL 及全范围 DNL 未测。
