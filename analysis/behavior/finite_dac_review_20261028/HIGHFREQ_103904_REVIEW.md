# 近 1 MHz N256 与低频等谱：独立回读

103904 的两次实际输入频率均为 `996093.75 Hz`（Fs 5 MHz、N256、bin 51），比 1 MHz 低 0.390625%。每次有 260 条实际 RX ready：ID 0–259、epoch 1、valid 全为 1，其中 ID 4–259 为选中 256 条；全部 RX RAW6 与同 ID/epoch 的 ADC RAW6 逐位相同。独立计算五项 FFT 指标如下：

| DAC 配置 | SNR (dB) | SNDR (dB) | SFDR (dB) | THD (dB) | ENOB (bit) |
|---|---:|---:|---:|---:|---:|
| off / 0 | 110.150096 | 109.827136 | 123.088592 | −121.273976 | 17.951352 |
| on / 1 ns | 107.249369 | 106.913367 | 118.614808 | −118.194717 | 17.467337 |

相对于各自 MATLAB 保存指标，NumPy 五项的最大绝对差为 `3.09e−10`（对应 dB 或 bit）；未新增判定容差。高频两次完整 P 只有 coupling enabled/τ、front τ 和 DAC NI 标记四处不同；高/低频同 τ 的 P 仅输入频率、前端输入频率和 `xFE0` 不同。四次 as-run 的 87 个源码文件 SHA、公开选片 plan、原生边与 solver 参数相同；实际各自 SLX 容器和 P 保持各自身份。

与 `97656.25 Hz`（bin 5）的同 τ 运行比较，**两个 τ 案例的 256 个 code 和 D1/D2/DT 均满足同一个精确时间置换**。若 `j=0` 对应 ID4，则

```text
j_low = (215 * j_high + 88) mod 256
```

两组各自 256 个整数码均唯一，按同一位置直接对照各有 254 处不同，但经过此置换 256/256 匹配。`51 ≡ 215×5 (mod 256)` 且 215 的模 256 逆元为 231，因此双边 DFT 功率按 `k_low=(231*k_high) mod 256` 重排；H2–H10 的实际频点也对应。重排后计算所得双边功率最大绝对差分别为 `8.88e−16`、`1.78e−15 V²`。**排序多重集相同本身不足以保证 FFT 相同**；这里的实际仿射时间置换与频点重排才支持这一组等谱解释。

这不是模拟波形逐位相同：实际 CNV 时的前端采样值按同一置换对应后，最大差约 `1.796e−13 V`，仅 8/256 个数值完全相等。本次模型采样建立 τ=0、孔径 jitter 关闭，且其他非理想按本批 P 配置；该结果不能证明 ADC 对频率普遍不敏感，不能覆盖未开启的采样带宽、抖动、比较器噪声或真实器件效应。比较器 timeout 没有独立观测，INL/DNL 未测；近 1 MHz 的数值也不是精确 1 MHz、PVT 或硅片签核。
