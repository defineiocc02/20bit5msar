# Simulink 模型分层、非理想与实施门禁

本文件从属于 SPEC.md。先保留成电原架构做对照，再只改前端；所有数字算法在 Simulink 系统内有独立、可检查的子系统。模型尚未在 MATLAB 运行。

## 1. 固定的顶层子系统

| 子系统 | 必须可观察的输入/输出/状态 |
|---|---|
| StimulusAndDriver | AINP/AINN、输入VCM、驱动器状态、源阻抗；精确x(t)供孔径时刻求值 |
| ClockAndBankScheduler | CNV、bank、sample_id、真实事件时刻、非重叠与busy；A/B保持/采集状态 |
| SamplingDAC1Banks | 两组物理电容、保持电荷、实际采样时刻；当前bank的DAC1残差 |
| Coarse6AndSAR1 | 6b coarse辅助、细判决、D1[10:0]、EOC1；不引入ADI 3b Flash |
| FrontendDEMAndDither | 合法物理掩码、注入命令、PRNG/计数；开关默认关闭，逐项接入 |
| ReferenceAndVCM | 外部驱动等效R/L/C、参考电压状态、每次抽取电荷、VCM扰动 |
| ResidueAmplifier | 32×标称增益、动态状态、AZ状态、输出噪声、限幅、bank/sample归属 |
| CINCAndDAC2 | VX/VY、CINC初始电荷、DAC2实际电容、replica路径和开关扰动 |
| CTSAR2 | 12个原始判决D2、对应时间、比较器噪声/失调/延迟及真实EOC2 |
| TrackingLoop8 | 8个DT、7个顺序反馈单元、每拍比较前后顶板残差；迟到/溢出标记 |
| RawRecordAndSerializer | 同sample_id配对、N−2选择、32bit帧、BANK/OVR、快照/复位状态 |
| FPGA_SINC2AndCalibration | 帧内滤波、前景训练/冻结系数、dither消除、位权/RA/bank修正及D20 |
| Observers | 码域/电荷/调度不变量、错误定位、FFT、spur、噪声分解与覆盖报告 |

模拟节点用double电压/电荷；物理开关用logical；D1/D2用无符号原始位向量；DT明确0/1或±1编码；ID与时间戳独立携带。初版数字算法可用基本块、Stateflow或显式状态的MATLAB Function块；不能把整颗ADC封装成不可观察的一段脚本，不能用外部Python runner替代子系统。定点化在浮点参考等价后单独开展。

## 2. 事件与相位候选

相邻转换周期的采集/转换在不同bank上重叠。下表是**180nm/5MS/s下的初始预算A**，不是原论文逐沿时序或硬件STA结果。后端核心目标≤180ns，保留20ns以上余量；模型必须拒绝越界事件，不能把超时结果强行设VALID。

| 相对采样边沿 | 当前转换bank | 另一bank |
|---|---|---|
| 0–30ns | 6b coarse辅助；RA AZ/复位 | 持续采集 |
| 30–55ns | 5个细决策槽，每槽5ns；一级码权待核定 | 持续采集 |
| 55–80ns | 一级残差接入RA，CINC按规定释放，RA先建立25ns | 持续采集 |
| 80–140ns | 12个二级原始决策槽，每槽5ns；RA持续演化 | 持续采集 |
| 140–160ns | 8次tracking，初始候选窗口20ns | 持续采集 |
| 160–175ns | 锁存同样本D1/D2/DT，原码配对 | 持续采集 |
| 175–200ns | RA/CT复位、路由与非重叠余量 | 完成采集，边沿后互换 |

论文对照profile仍保留8次/10ns；工程候选的20ns旨在放宽内部速度，必须重新评估RA噪声相关性和收益，不能沿用7dB结论。**M2与M3的前端交织对照必须使用同一组后端参数、相位与10ns tracking窗口，先只改变前端；上表的175ns/20ns工程候选在该对照之后作为独立时序实验，不自动替换主体基线。**10/20/40ns窗口都单列实验；40ns可消耗上述余量，但仍须通过≤180ns核心目标，必要时重新分配相位。不能把5MHz输出时钟当成tracking内部比较时钟，也不能把M·Fs直接当作本地重复时钟。

比较器先读取当前模拟状态和当时噪声，再锁存判决；随后更新物理DAC反馈，影响下一个比较事件。双积分器当前值/上一值的使用顺序必须书面固定，并用有限序列oracle验证。

## 3. 非理想项放在哪里

| 非理想 | 模型与状态 | 首个验收 |
|---|---|---|
| bank/slice静态孔径skew | 每芯片固定δt，实际采样x(t+δt)；bank与slice两层分开 | 单音相位/幅度与小信号δt·x'近似一致 |
| 随机jitter | common及local独立过程/指定协方差，逐CNV生成 | 公共jitter单独符合正弦jitter噪声关系 |
| 占空比/非重叠失配 | 改变真实采集窗口和开关边沿，不只改采样值 | 路由无重叠，tACQ、保持时间和guard均为正 |
| 有限输入建立 | 驱动器+Ron(Vin)+真实电容负载的连续状态 | 输入频率/幅度/源阻抗扫描；不能把DC增益错当建立误差 |
| kT/C采样噪声 | 按同一电容定义求方差，每次采集一次，保持该电荷噪声 | 噪声方差随T/C缩放；差分相关性明确 |
| 保持泄漏/电荷注入 | 保持期间droop；开关边沿ΔQ/C；支持输入相关项 | 延长保持时间与切换极性符合预期 |
| 电容失配/梯度/寄生 | 固定物理电容数组，按面积/单位单元缩放；桥电容/顶板寄生进矩阵 | 电荷守恒；单个物理电容扰动只影响使用它的样本 |
| bank gain/offset/bandwidth | 固定每bank参数，与公共误差分开 | AB固定调度显示Fs/2及Fs/2±fin相关spur |
| 参考动态 | 开关状态决定ΔQ；Cref储能及buffer R/L/C恢复；参考噪声单独注入 | 码型历史/最坏跳变与恢复；不能只加常数gain误差 |
| RA增益/非线性 | 有限DC增益、极点/压摆/限幅、bank切换记忆 | 增益与建立逐项扫描，超量程可见 |
| RA AZ与放大噪声 | AZ样本内相关；放大噪声为带限连续过程 | 共模/低频误差不被虚假除M；按采样时刻协方差核对平均收益 |
| 比较器 | 固定offset+每次噪声；输入相关再生延迟/超时概率 | 决策概率、延迟尾部与越界VALID分别检查 |
| DAC2回踢/replica | 实际开关跳变经耦合注入VX/VY；幅度与路径延迟失配 | replica开关对照，零失配极限与延迟扫频 |
| DEM/dither量化/饱和 | 掩码/实际电荷/真实幅度；估计权重消除；分支余量 | 标称不变量、同标签消除、错误标签负对照、RA/ADC2不溢出 |
| 数字系数/有限字长 | 舍入、饱和、系数量化和乘加增长 | 与double参考比较；不允许wrap被当噪声平均掉 |

失配是在chip层抽样一次并冻结，不能每个样本重抽；随机源分开设seed，避免关闭一个效应改变其他随机序列。对共享参考、driver和RA记忆保留跨样本状态；不能把每次调用模型视为独立电路。

静态skew和随机jitter不可混用。ADI的约0.6ps披露仅作该论文参考，不是本项目既定σjitter。建议诊断扫点为静态skew 0/0.5/1/2/5/10ps，增益失配0/10/50/100/500ppm，offset 0/0.1/0.5/1/2 LSB20，带宽失配0/0.1/0.5/1/2%；这些是探索输入A，不是180nm PDK统计。固定AB、因果shuffle和失配校准前后使用同一物理chip对照。

## 4. 噪声与量程预算

主测试−1dBFS的输入正弦Vrms=`4.096·10^(−1/20)/sqrt(2)`。SNR100dB对应允许随机误差rms约25.81μV；SINAD98dB对应总误差rms约32.50μV。THD−105dBc若恰达上限，结合SNR100dB时SINAD约98.81dB，保留约0.81dB相对98dB目标的余量。

初始随机误差功率分配A：采样50%、RA放大后滤波15%、AZ8%、比较器滤波后7%、参考/驱动10%、量化/数字5%、余量5%。均折算输入端，和为100%。RA与比较器的“滤波后”方差由闭环仿真测得，不能直接设置为滤波前/8。共享噪声与相关项另计协方差，不能只做RSS。

28pF口径尚待确认，因此不得宣称物理kT/C预算已经闭合。需分别检查“28pF每边”与“28pF差分总和”解释，再依据原图/电路输入冻结；目标误差功率、分配比例与物理噪声模型必须同时满足。

RA输出等效二级窗口1.024V只由理想2bit冗余导出。开启dither、失配、offset、未建立与kickback后，逐事件校验 `|G·r+扰动|` 位于允许窗口；不能假设Rov=4天然覆盖任何dither幅度。正式的DAC1/DAC2冗余权重、CINC与参考连接表仍列为缺失输入，先建立明确的候选并保留来源标签。

## 6. 验收用例

- V01：SAR1/2阈值、原始位权、极性和理想残差范围；饱和/并列阈值边界。
- V02：CINC复位/释放与RA连续驱动；错误插入RA后S/H的负对照。
- V03：8决策/7更新；首末拍、双积分顺序、归一化及复位。错误同拍反馈必须被检测。
- V04：RA带限噪声协方差；独立/完全相关噪声极限。完全相关误差不得自动获得9dB收益。
- V05：M=1/2/4/8/16与窗口10/20/40ns分开扫描；修改M或窗口时说明哪一项固定。
- V06：A/B理想等价；prime、首样本0/A、样本连续性和真实EOC。
- V07：静态skew与随机jitter分别注入；100kHz/1MHz/高频诊断，区分噪声和周期spur。
- V08：固定chip的C/R/寄生/offset/gain/bandwidth失配；同chip校准前后，不重抽一个更好的chip。
- V09：DEM实际物理映射/电荷守恒/单电容局部扰动；标签变化但物理不变的负对照。
- V10：dither模拟注入与同样本数字消除；错一拍/错尺度/错符号负对照；headroom失败显式报错。
- V11：18slice因果集合、spare采集、conv/acq互斥；禁止每拍独立随机选片。
- V12：前景校准独立训练/验证；冻结系数；只用可获得原码和配置，不读取真实物理参数。
- V13：32bit打包/解包与sideband，同sample_id；N−2首帧、丢帧、读中更新、abort、OVR、复位。
- V14：求解步长减半/模拟带宽提高后的收敛；差异>0.1dB时继续查数值误差。
- V15：FFT带宽、相干/加窗、谐波计数、SNR/SINAD/SFDR/ENOB和输入幅度一致；含噪DNL/INL必须给记录量与置信度。

参数扫点未给证据时不能写成工艺容差；BER低于记录可分辨能力时报告置信上界，不能因未见错误就填零。
