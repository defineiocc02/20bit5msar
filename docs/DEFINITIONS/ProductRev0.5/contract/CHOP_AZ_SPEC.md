# SAR20-5：斩波辅助自动调零规格增补

日期：2026-10-20；适用：**仅20位、5 MS/s方案**。用户要求纳入设计，实际噪声收益、开关实现和相位长度仍待验证。16位产品不加入本项。

## 1. 原始依据及移植边界

原始资料为本机 `/Users/zhaoyi/Downloads/C32_C32-1.pdf`，42页：Zongnan Wang等，北京大学/清华大学，VLSI 2025 C32-1，*An 88.8dB-SNDR 6-MS/s Pipelined SAR ADC with A Closed-Loop Dynamic Amplifier Featuring Highly-Linear Full-Scale Output Swing*。

- 第29–32页：采样/AZ、一级转换、RA、二级转换的原始工作状态。

- 第34–35页（Slide 33–34）：奇数周期跳过AZ、反转输入，复用偶数周期的AZ存储状态；输出组合消除共同AZ误差。

本项目移植**跨两次共享RA服务保持同一AZ状态、残差信号换向、数字符号恢复及相关处理**的机制。不是复刻其6b/12b位数、FGA/CP-FIA或6 MS/s测量结果。本项目仍为A/B采样/DAC1、10b DT一级、共享32倍Ringamp、CINC连续耦合CT二级、TA8；RA后不得增加DT采样保持器。

下文残差端换向、四样本极性日历、Ringamp状态保持是本项目的实现提案，**不是原PPT已验证的电路**。旧ADI/PKU融合报告仅作历史推导参考，不继承其40 MS/s、GmR+OTA或DT后端日历。

## 2. 必须分开的噪声与算法

1. 本机制主要处理调零时保存在RA内部AZ节点上的误差及相关低频项。它不直接消除输入采样kT/C、一级DAC失配、参考噪声或每次新生成的RA宽带噪声。
2. 同一样本的8次tracking应看到相同的AZ存储状态；不能每次tracking重抽独立AZ噪声，也不能既给TA8一次平均增益、又给斩波一次任意降噪系数。
3. SINC²是帧内DT重建；跨样本斩波解调/低通是另一条处理链；DAC位权与RA增益的前景校准又是另一项。三者分别开关、分别验收。
4. LMS仅是估计校准系数的一种方法。首版允许PC前景训练后冻结系数，由FPGA重建；不要求片内或后台LMS。可实现的校准不得读取仿真的真实失配/噪声状态。

## 3. 电路功能及内外分工

新增内部控制：`AZ_WRITE`、`AZ_HOLD`、`RST_SIG`、`RESIDUE_POL`、`READOUT_EN`；它们是内部相位，不增加封装引脚。

- 将**完整差分DAC1残差**在进入共享RA前按极性正接/交叉接；包含信号与DAC1扣除项，不能只反相输入信号或只翻一个电容。
- RA闭环反馈极性保持负反馈。数字输出不能冒充模拟换向，也不能通过反转反馈导致正反馈。
- 共同AZ状态保存在真实候选AZ节点/电容；每次仍清除前次信号残留及FIA输出/CT初始状态。`RST_SIG`不得刷新或放掉需要保持的AZ电荷。
- Jin Ringamp的局部CMFB、AZ、FIA输出及CRES复位必须重新逐节点核对。不能仅因PPT有CBIAS，就假定现有Ringamp已具备可跨周期保持的同等节点。
- CINC、主DAC2和replica分支每次按既定CT相位初始化；两极性的残差范围、共模、回踢及replica延时均需验证。不得直接按位取反D2/DT来假装有符号模拟换向。
- 两bank继续各采集一个完整名义周期。外部AIN采样极性不翻转，差分输入对仍同时提供给A/B；换向发生在一级判决结束后的残差读出端。
- 数字符号恢复和跨样本滤波放在FPGA/Simulink数字子系统。片内高速tracking反馈保留。

## 4. 固定相位与标签合同

名义Ts=200 ns，保持5 MS/s原始吞吐。定义 `pair_id=floor(sample_id/2)`；每对的第一个样本更新AZ，第二个样本保持同一份AZ状态。两次RA服务间隔200 ns；AZ更新间隔400 ns。保持200 ns不代表允许RA或CT占用两个转换周期。

初始工程候选采用四样本极性序列 `[+1,-1,-1,+1]` 循环，避免bankA永远正接、bankB永远反接。每对内极性仍相反。它是本项目设计选择；原PPT的基本机制另保留为`[+1,-1]`对照。

| sample_id mod4 | bank | pair位置 | 残差极性s | AZ动作 |
|---|---|---|---|---|
| 0 | A | first | +1 | 更新新AZ状态 |
| 1 | B | second | −1 | 保持同一pair状态 |
| 2 | A | first | −1 | 更新新AZ状态 |
| 3 | B | second | +1 | 保持同一pair状态 |

换向只在残差通路断开、前一CT/TA完成后进行；先隔离，再选择极性/清信号状态，然后AZ更新或保持，最后闭合残差通路。AZ必须在RA有效放大前建立；RA与CT仍可按已验证方案重叠。不能在前一帧CT tracking期间刷新共享AZ状态。

首版核心窗口仍为≤180 ns目标。暂不编造开关死区、AZ写入或保持建立的固定纳秒值；Simulink显式保留这些参数并检查总日历，晶体管/PEX结果闭合后再冻结。

复位清 `sample_id/bank/pair/polarity/az_valid`。第一笔有效样本从ID0、bankA、pair0、s=+1开始。中止、漏读或无效记录不得推进/回退模拟极性日历，日历只随CNV/sample_id推进。禁止把不同pair、不同复位epoch或缺一笔的记录凑成完整相消对。

外部接口已按Rev0.3选定AD7961指定配置的引脚/电压兼容设计输入，原BANK/OVR侧带及自定义32脚已废止。FPGA可由其产生的CNV计数、复位epoch和固定N−2时隙推导BANK/POL/PAIR；当前32位帧不新增元数据，由Rev0.3固定槽合同规定标签推导，不能借用原厂模拟/输出脚新增控制。仿真内部必须保留显式标签进行核验。

## 5. 行为模型必须实现的状态

至少包含：`az_valid`、`az_pair_id`、`az_state`、`az_age_s`、`polarity`、`signal_reset_state`、`sample_id/bank`。多物理AZ节点可用定长向量表示，不能仅用最终输出噪声标量代替全部存储过程。

AZ更新时抽取一次该pair的存储噪声，并按有限建立时间写入；保持周期不重抽该噪声。保持候选模型为：

`u_hold = lambda*u_pair + eta_hold + k_history*r_previous + delta_injection`。

其中泄漏/保持噪声、前次残差信号耦合、极性切换注入分开参数化，均可置零用于理想机理检查。AZ存储噪声、RA本次宽带/低频噪声、输入kT/C和CT比较器噪声保持独立来源及必要相关性。

验证用的最简观测关系为：

`vRA[n] = G[n]*s[n]*r[n] + K[n]*u_pair[n] + e_new[n]`。

可实现的外部重建为：

`xhat[n] = V_DAC1_est(D1[n]) + s[n]*F_CT(D2[n],DT[n])/G_est`。

`F_CT`必须采用实际候选DAC2/CINC/TA编码与归一化；D1、D2不是直接可加的两补码整数。解调后共同AZ误差带相反符号；不准由FPGA直接减去模型真值`u_pair`。

正反信号增益、AZ耦合系数和保持误差可能不同，需扫描它们；即使RA物理共享，也不自动保证两次传递系数相同。应保留真实饱和/过量程/判决超时标记，不得丢弃异常样本后只报漂亮频谱。

## 6. 输出速率与噪声收益的边界

始终保存5 MS/s逐样本原码与解调后的逐样本结果。**不把配对平均后的结果冒充5 MS/s、全Nyquist独立样本。**

- 成对非重叠平均可用于机理验证/精密低带宽模式，输出率为2.5 MS/s；有用信号本身也成为相邻样本均值，须报告频响、群延迟和新的Nyquist带宽。
- 全速输出可另外经过明确定义的低通滤波而不降采样；它仍改变信号/噪声带宽。与普通AZ比较时，必须使用相同滤波器、相同带宽和相同采样率口径。
- 理想共享AZ的正反误差呈高通型相关谱；全Nyquist积分功率不凭空降低。收益集中在低带宽模式，整机收益取决于AZ误差占比和新增开关/保持误差。
- 不写“AZ噪声全部消除”“整机提升10dB”或“采样kT/C取消”为保证指标。100kHz主测与1MHz扩展目标维持原定义，分别报告原始流和明确带宽处理后的结果。

## 7. Simulink修改与验收清单

必须提供四个公平对照，固定同一颗虚拟芯片、失配、输入和后处理：A普通逐次AZ；B逐次AZ但换向；C隔次保持但不换向；D隔次保持＋换向＋正确解调。D为20位设计要求，A/B/C为验证开关，不新增16位功能。

1. AZ状态在偶/奇两次服务真实复用；B不得因为“chop enable”自动降低白噪声。
2. 独立注入已知AZ扰动，核对两次输出灵敏度/反号；独立注入输入采样噪声，确认它未被错误删除。
3. 关闭一切非理想时，任意两笔不同输入的重建仍正确；输出组合的信号平均效应与公式一致。
4. 扫描保持泄漏/注入、AZ建立、正反增益/延时、CINC初值、replica误差、RA历史与CT过载。
5. 5 MS/s时孔径不漂移、不丢样；跨周期保留AZ不妨碍每周期清除信号历史。TA8与CAAZ联合状态可追溯。
6. 打断一笔/复位/漏读时丢弃该不完整配对，滤波器按策略重同步；不跨pair/epoch组合。
7. 同时提交原始流/同带宽滤波/2.5MS/s配对结果，分别统计噪声、SNDR/SFDR、频响与延迟。未执行MATLAB/Simulink前只报告源码/静态检查，不报告仿真通过。

未闭合门点：Ringamp中可跨周期保存的实际AZ节点、选择性复位、差分残差换向网络、保持扰动预算、CT量程与replica匹配。模型可先实现明确候选并标假设；不得用一个理想降噪乘数替代这些缺口。
